# 005. GOODS 섹션 및 006. FOOTER 반응형 구현

**타겟 사이트:** https://www.mandaco.co.kr/  
**작업 대상:** GOODS 섹션 및 FOOTER  
**참조 이미지:** 각 영역별 데스크탑 → 태블릿 → 모바일 순서

## 1. GOODS 섹션 화면 구성

- 첨부한 첫 번째 3장의 이미지를 분석하여 GOODS 섹션을 구현한다.
- 전체 배경은 화이트이며 상단 중앙에 `GOODS` 타이틀과 짧은 구분선을 배치한다.
- 굿즈는 상품 이미지와 상품명으로 구성된 카드 형태로 표시한다.
- 상품 목록은 좌우 화살표로 이동하는 가로형 캐러셀(Slider)로 구현한다.
- 상품 이미지는 원본 비율을 유지하고 카드 내부에 자연스럽게 배치한다.
- 카드 간격, 테두리, 이미지 배경색, 텍스트 정렬은 참조 이미지를 따른다.
- 캐러셀 하단 중앙에 `굿즈 보러가기` 버튼을 배치한다.

## 2. GOODS 인터랙션

- 좌우 화살표 클릭 시 상품 카드가 가로 방향으로 이동한다.
- 데스크탑과 태블릿에서는 4개의 상품 카드가 보이도록 구성한다.
- 모바일에서는 상품 카드 1개와 다음 카드 일부가 보이는 가로 슬라이더로 전환한다.
- 모바일에서 터치 스와이프를 지원한다.
- 첫 번째·마지막 상품에 도달하면 해당 방향 화살표를 비활성화한다.
- 슬라이더 이동 시 카드가 잘리거나 레이아웃이 깨지지 않도록 한다.
- 굿즈 데이터는 추후 상품 추가 및 변경이 쉽도록 관리한다.
- 상품별 실제 판매 URL이 제공된 경우 카드 클릭 시 해당 상품 페이지로 이동한다.

**굿즈 보러가기 버튼 연결 URL:**  
https://marpple.shop/kr/mandac

외부 링크는 새 탭에서 열린다.

## 3. GOODS 반응형 구성

**데스크탑 (1920px 기준)**
- 중앙 정렬된 GOODS 제목과 구분선.
- 상품 카드 4개를 가로로 배치한다.
- 캐러셀 좌우에 이동 버튼을 배치한다.
- 하단 중앙에 굿즈 보러가기 버튼을 배치한다.

**태블릿 (1024px 이하)**
- 4개의 상품 카드가 보이는 가로형 구성을 유지한다.
- 카드 크기와 간격, 제목 및 버튼 크기를 화면 폭에 맞게 조정한다.

**모바일 (768px 이하)**
- 제목과 구분선은 중앙 정렬을 유지한다.
- 한 번에 상품 카드 1개와 다음 카드 일부를 노출한다.
- 좌우 이동 버튼을 유지하고 터치 스와이프를 지원한다.
- 하단에 굿즈 보러가기 버튼을 중앙 정렬한다.

## 4. FOOTER 화면 구성

- 첨부한 마지막 3장의 이미지를 기준으로 FOOTER를 구현한다.
- GOODS 섹션 바로 아래에 배치한다.
- 전체 배경은 짙은 네이비 컬러이며 텍스트는 화이트 및 연한 회색을 사용한다.
- HARO 로고 텍스트, 브랜드 소개 문구, 이메일, 저작권 문구, SNS 아이콘으로 구성한다.
- 참조 이미지의 글자 크기, 줄 간격, 여백과 정렬을 유지한다.

**SNS 아이콘**
- 네이버 블로그
- Behance
- Instagram

각 아이콘은 해당 채널로 이동하는 링크로 구현한다. 실제 URL이 확인되지 않은 채널은 임의의 주소로 연결하지 않는다.

## 5. FOOTER 반응형 구성

**데스크탑 (1920px 기준)**
- 왼쪽에 HARO 로고, 소개 문구, 이메일을 세로로 배치한다.
- 하단 왼쪽에 저작권 문구를 배치한다.
- 하단 오른쪽에 SNS 아이콘 3개를 가로로 배치한다.

**태블릿 (1024px 이하)**
- 데스크탑의 좌측 정렬 구조를 유지한다.
- 화면 폭에 맞춰 전체 여백과 텍스트 크기를 조절한다.
- SNS 아이콘은 오른쪽 하단에 유지한다.

**모바일 (768px 이하)**
- HARO 로고, 소개 문구, 이메일은 왼쪽 정렬을 유지한다.
- 본문 텍스트는 화면 폭에 따라 자연스럽게 줄바꿈한다.
- 저작권 문구는 하단 중앙 정렬로 변경한다.
- SNS 아이콘은 저작권 문구 아래에 가로로 배치하고 중앙 정렬한다.
- 각 콘텐츠 사이의 세로 간격을 참조 이미지에 맞게 조정한다.

## 6. 반응형 미디어쿼리

Desktop First 방식으로 구현한다.

- 데스크탑: `1025px 이상` (1920px 디자인 기준)
- 태블릿: `@media (max-width: 1024px)`
- 모바일: `@media (max-width: 768px)`

기존 CSS를 최대한 재사용하고 태블릿 → 모바일 순서로 필요한 스타일만 재정의한다.

## 7. 구현 및 관리 조건

- 기존 STORY 섹션 바로 다음에 GOODS 섹션을 추가한다.
- GOODS 다음에 FOOTER를 배치한다.
- 기존 HTML/CSS/JavaScript 및 다른 섹션의 기능은 변경하지 않는다.
- 실제 상품 이미지는 프로젝트 내 이미지 파일을 우선 활용한다.
- 상품 이미지가 없는 경우 임의로 다른 상품 이미지를 생성하지 않는다.
- 캐러셀과 반응형 레이아웃을 독립적으로 구현한다.
- FOOTER는 일반 문서 흐름에 배치하고 화면에 고정하지 않는다.
- 헤더의 고정 및 스크롤 기능은 기존 상태로 유지한다.
- 데스크탑·태블릿·모바일에서 레이아웃, 캐러셀, 버튼 링크 및 가로 넘침을 검증한다.
- 완료 후 변경 내용과 검증 결과를 `task-history/task.md`에 기록한다.
- 기존 `prompt.txt`는 임의로 수정하지 않는다.
