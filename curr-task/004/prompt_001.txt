# 005. GOODS 섹션 — Swiper 슬라이더 구현

첨부된 3장의 화면 덤프 이미지를 분석하여 기존 GOODS 섹션과 동일한 디자인으로 구현해 주세요.

**이미지 순서:** 데스크탑 → 태블릿 → 모바일

## 1. 화면 구성

- 전체 상품 이미지는 총 8장이다.
- 모든 상품 이미지는 동일한 크기의 카드에 표시한다.
- 데스크탑에서는 8장 중 4개 상품이 한 화면에 보인다.
- 나머지 4개 상품은 Swiper 슬라이더를 통해 확인한다.
- 카드에는 상품 이미지와 상품명을 표시한다.
- 제목, 카드 크기, 정렬, 간격, 좌우 화살표 및 하단 버튼은 첨부 이미지를 기준으로 구현한다.

## 2. Swiper 인터랙션

- **Swiper.js 라이브러리**를 사용한다.
- 좌우 화살표 클릭 시 상품 카드가 1개씩 부드럽게 이동한다.
- 모바일에서는 손가락 스와이프를 지원한다.
- 첫 번째와 마지막 위치에서는 해당 방향 화살표를 비활성화한다.
- 자동 재생 및 무한 반복은 사용하지 않는다.
- 슬라이드 이동 시 이미지 크기와 카드 높이가 달라지지 않도록 한다.

## 3. 반응형 레이아웃

Desktop First 방식으로 구현한다.

**데스크탑: 1025px 이상**
- 상품 카드 4개 노출
- 좌우 화살표 배치

**태블릿: 769~1024px**
- 상품 카드 4개 노출
- 화면 폭에 맞춰 카드 크기와 간격 조절

**모바일: 768px 이하**
- 상품 카드 1개와 다음 카드 일부 노출
- 좌우 화살표 및 터치 스와이프 유지
- 슬라이더 영역 밖으로 가로 스크롤이 발생하지 않도록 처리

## 5. 구현 조건

- 기존 HTML/CSS/JavaScript 구조를 최대한 유지한다.
- 실제 제공된 상품 이미지 8장을 사용한다.
- 상품 이미지의 비율을 유지하고 카드 크기를 통일한다.
- 기존 GOODS 외 다른 섹션은 수정하지 않는다.
- Swiper를 중복 초기화하지 않는다.
- 데스크탑·태블릿·모바일 화면에서 표시 개수, 화살표, 스와이프 및 가로 넘침을 검증한다.
- 작업 완료 후 `task-history/task.md`에 변경 내용을 기록한다.
- 기존 `prompt.txt`는 수정하지 않는다.
