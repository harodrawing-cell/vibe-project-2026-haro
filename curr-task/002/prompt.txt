# [작업 요청] EMOTICON 섹션 반응형 웹 구현

첨부한 3장의 디자인 이미지를 분석하여 기존 HARO 웹사이트에 `EMOTICON` 섹션을 구현해 주세요.

**참조 이미지 순서**

1. `emo--dt.png` : 데스크톱 디자인
2. `emo-tab.png` : 태블릿 디자인
3. `emo-mob.png` : 모바일 디자인

**작업 목표**

- 참조 이미지에 최대한 일치하는 반응형 웹 구현
- 데스크톱, 태블릿, 모바일 간 레이아웃 변화 정확하게 반영
- 기존 프로젝트의 HTML, CSS, JavaScript 구조 유지
- 기존 캐릭터 이미지와 리소스 재사용
- 불필요한 코드 변경 및 중복 스타일 생성 방지

- 이미지 크기는 콘텐츠 너비에 맞춰 유동적으로 조절

**이미지 순서**

1. 하로 고양이 이모티콘
2. 몽돌·부싯돌 이모티콘
3. 캐릭터 블로그 구분선 이미지

## 6. 모바일 디자인 구현

**참조 이미지: `emo-mob.png`**

### 전체 레이아웃

- 흰색 배경 유지
- 상단에 HARO 로고와 햄버거 메뉴 표시
- 기존 모바일 헤더 재사용
- 섹션 타이틀 중앙 정렬
- 타이틀 아래 검은색 가로선 배치
- 충분한 상단 여백 확보

### 이미지 갤러리

데스크톱의 가로 4열을 모바일에서는 **2열 × 2행**으로 변경합니다.

배치 순서는 다음과 같습니다.

| 왼쪽 | 오른쪽 |
|---|---|
| 하로 | 몽돌·부싯돌 |
| 구분선 1 | 구분선 2 |

- `display: grid` 사용
- `grid-template-columns: repeat(2, minmax(0, 1fr))`
- 이미지 비율 `1:1` 유지
- 이미지 사이 간격 약 8px
- 갤러리 좌우 여백 약 24px
- 이미지의 왜곡 및 잘림 방지
- 이미지 순서 변경 금지

### 타이틀과 갤러리 간격

모바일 참조 이미지에서는 타이틀 및 구분선 아래에서 이미지 갤러리가 시작되기까지 넓은 여백이 존재합니다.

해당 간격을 데스크톱과 별도로 분석하여 모바일 미디어쿼리에서 조정합니다.

### 소개 문구 및 버튼

모바일 첨부 이미지에는 소개 문구와 버튼이 화면 하단에 나타나지 않습니다.

따라서 다음 사항을 확인합니다.

- 원래 섹션의 콘텐츠가 단순히 화면 아래에 있는 것인지 확인
- 기존 콘텐츠를 임의로 삭제하거나 숨기지 않기
- 별도의 숨김 요구사항이 없다면 갤러리 아래에 정상적으로 배치
- 모바일에서 버튼 너비, 줄바꿈 및 간격 최적화

## 7. 반응형 CSS 구현 지침

다음 사항을 준수해 주세요.

1. CSS Grid 또는 Flexbox를 활용합니다.
2. 고정 픽셀에만 의존하지 않고 `%`, `max-width`, `minmax()`, `clamp()`를 적절히 활용합니다.
3. 이미지 크기는 부모 요소의 너비에 따라 반응하도록 작성합니다.
4. 이미지 원본 비율을 유지합니다.
5. 미디어쿼리마다 필요한 CSS 속성만 재정의합니다.
6. 기존 CSS와 중복되는 선택자를 무분별하게 추가하지 않습니다.
7. 수평 스크롤이 발생하지 않도록 합니다.
8. 이미지가 화면 밖으로 넘치지 않도록 합니다.
9. 모바일에서 헤더 및 햄버거 메뉴가 정상 작동하도록 유지합니다.
10. 레이아웃 수정으로 다른 섹션이 변경되지 않도록 스타일 범위를 제한합니다.

        # 003. EMOTICON 섹션 — Swiper 슬라이더 기능 추가

        ## 1. 작업 목표

        기존 GOODS 섹션에 적용된 Swiper 기능을 EMOTICON 섹션에도 동일하게 구현한다.

        - 기존 EMOTICON 섹션의 디자인, 카드 크기, 이미지 비율, 간격을 유지한다.
        - 기존 이미지에 새로운 이미지 4장을 추가한다.
        - Swiper.js를 사용하여 좌우 슬라이드 기능을 구현한다.
        - **4초 간격 자동 재생(Autoplay)과 무한 반복(Loop)을 적용한다.**

        ## 2. 이미지 추가

        기존 이미지 외에 다음 이미지 4장을 추가한다.

        - `images/img-dt10`
        - `images/img-dt11`
        - `images/img-dt12`
        - `images/img-dt13`

        실제 프로젝트의 이미지 파일명과 확장자를 확인하여 적용한다.

        - 기존 이미지와 추가 이미지의 표시 크기를 통일한다.
        - EMOTICON 섹션에 설정된 기존 이미지 크기와 비율을 준수한다.
        - 원본 이미지가 찌그러지거나 과도하게 잘리지 않도록 한다.
        - 기존 이미지의 순서를 유지하고 새로운 이미지 4장을 뒤에 추가한다.

        ## 3. Swiper 기능

        기존 GOODS 섹션의 Swiper 구성 방식을 재사용하되 다음 옵션을 적용한다.

        - `autoplay.delay: 4000` — 4초 간격 자동 이동
        - `loop: true` — 마지막 슬라이드 이후 첫 번째로 자연스럽게 연결
        - `speed: 600` — 부드러운 이동 애니메이션
        - `slidesPerGroup: 1` — 한 번에 카드 1개씩 이동
        - `autoplay.disableOnInteraction: false` — 사용자가 조작한 후에도 자동 재생 유지
        - 좌우 화살표 버튼 지원
        - 모바일 터치 스와이프 지원
        - 무한 반복 구조이므로 좌우 화살표를 끝에서 비활성화하지 않는다.

        GOODS 섹션의 기존 Swiper 옵션은 변경하지 않는다.

        ## 4. 반응형 구성

        Desktop First 방식으로 구현한다.

        **데스크탑 (1025px 이상 / 1920px 기준)**
        - 기존 EMOTICON 카드 크기와 레이아웃 유지
        - 기존 화면 구성에 맞는 표시 카드 개수 유지
        - 좌우 화살표와 자동 슬라이드 적용

        **태블릿 (769~1024px)**
        - 기존 태블릿 디자인의 카드 크기와 표시 개수를 준수한다.
        - 화면 폭에 맞춰 카드 간격을 조정한다.

        **모바일 (768px 이하)**
        - 기존 모바일 EMOTICON 디자인과 이미지 크기를 유지한다.
        - 터치 스와이프 및 자동 재생을 지원한다.
        - 가로 넘침과 불필요한 페이지 스크롤을 방지한다.

        Swiper의 JavaScript 브레이크포인트는 라이브러리의 최소 너비 기준에 맞게 설정한다.
