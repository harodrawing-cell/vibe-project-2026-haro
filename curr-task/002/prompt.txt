# [작업 요청] EMOTICON 섹션 반응형 웹 구현

## 1. 작업 개요

첨부한 3장의 디자인 이미지를 분석하여 기존 HARO 웹사이트에 `EMOTICON` 섹션을 구현해 주세요.

**참조 이미지 순서**

1. `emo--dt.png` : 데스크톱 디자인
2. `emo-tab.png` : 태블릿 디자인
3. `emo-mob.png` : 모바일 디자인

**작업 목표**

- 참조 이미지에 최대한 일치하는 반응형 웹 구현
- 데스크톱, 태블릿, 모바일 간 레이아웃 변화 정확하게 반영
- 기존 프로젝트의 HTML, CSS, JavaScript 구조 유지
- 기존 캐릭터 이미지와 리소스 재사용
- 불필요한 코드 변경 및 중복 스타일 생성 방지

6. 실제 이미지 파일 경로

**필수 준수 사항**

## 3. 디자인 기준 및 브레이크포인트

**Desktop First 방식**으로 작성하고, 기존 프로젝트에 정의된 브레이크포인트가 있다면 이를 우선 적용합니다.

기존 기준이 없는 경우 다음을 사용합니다.

| 디바이스 | 화면 너비 | 레이아웃 |
|---|---|---|
| 데스크톱 | 1025px 이상 | 4열 |
| 태블릿 | 769~1024px | 4열 |
| 모바일 | 768px 이하 | 2열 |

모든 미디어쿼리는 `max-width` 방식으로 작성합니다.

참조 이미지의 화면 크기와 요소 위치를 비교해 비율과 간격을 추출하고, 정의된 브레이크포인트 사이에서도 레이아웃이 자연스럽게 유지되도록 구현합니다.

## 4. 데스크톱 디자인 구현

**참조 이미지: `emo--dt.png`**

### 전체 섹션

- 흰색 배경 사용
- 콘텐츠를 화면 중앙에 정렬
- 콘텐츠 최대 너비는 약 1080px을 초기 기준으로 설정
- 섹션 내부에 충분한 상하 여백 확보
- 레이아웃은 세로 방향의 중앙 정렬 구조

### 타이틀

- 텍스트: `EMOTICON`
- 섹션 최상단 중앙 배치
- 검은색의 두껍고 둥근 손글씨 느낌 폰트
- 타이틀 하단에 짧은 검은색 가로선 배치
- 타이틀과 가로선 사이 여백 유지

### 이미지 갤러리

- 이미지 총 4개
- 가로 4열, 세로 1행
- 정사각형 이미지 비율 유지
- 모든 이미지 동일 크기
- 이미지 간 간격 약 18px
- 이미지에 불필요한 그림자, 테두리, 모서리 라운드 추가 금지
- 이미지 크기는 콘텐츠 너비에 맞춰 유동적으로 조절

**이미지 순서**

1. 하로 고양이 이모티콘
2. 몽돌·부싯돌 이모티콘
3. 캐릭터 블로그 구분선 이미지
4. 블로그용 리뷰·예약·주차 구분선 이미지

### 소개 문구

이미지 갤러리 아래 중앙 정렬로 다음 문구를 표시합니다.

오늘도 적당히 덤덤한 하로  
네이버 OGA에서 만나보세요!

- 참조 이미지의 문구, 폰트 크기, 굵기, 줄 간격 반영
- 이미지 갤러리와 문구 사이 충분한 여백 유지
- 문구는 두 줄로 표시

### 버튼

소개 문구 아래 두 개의 버튼을 가로로 배치합니다.

- `OGQ 이모티콘`
- `카카오 이모티콘`

버튼 스타일:

- 흰색 배경
- 검은색 1.5~2px 테두리
- 둥근 캡슐형 버튼
- 검은색 텍스트
- 두 버튼 사이 간격 유지
- 콘텐츠 기준 중앙 정렬

버튼 링크는 기존 프로젝트에 등록된 URL을 사용하고, 확인되지 않는 경우 임의의 링크를 생성하지 않습니다.

## 5. 태블릿 디자인 구현

**참조 이미지: `emo-tab.png`**

태블릿에서도 이미지 4개를 한 줄에 유지합니다.

### 주요 변경점

- 콘텐츠 너비는 화면 너비에 따라 유동적으로 조절
- 좌우 여백 축소
- 이미지 갤러리는 4열 유지
- 이미지 간 간격 약 18~20px
- 이미지 비율 1:1 유지
- 제목 중앙 정렬
- 구분선 위치 유지
- 소개 문구와 버튼 중앙 정렬

**중요 사항**

데스크톱과 태블릿의 차이는 단순 확대·축소가 아니라, 화면 너비와 내부 여백 및 요소 간 간격을 참조 이미지에 맞춰 조정하는 방식으로 구현합니다.

## 6. 모바일 디자인 구현

**참조 이미지: `emo-mob.png`**

### 전체 레이아웃

- 흰색 배경 유지
- 상단에 HARO 로고와 햄버거 메뉴 표시
- 기존 모바일 헤더 재사용
- 섹션 타이틀 중앙 정렬
- 타이틀 아래 검은색 가로선 배치
- 충분한 상단 여백 확보

### 이미지 갤러리

데스크톱의 가로 4열을 모바일에서는 **2열 × 2행**으로 변경합니다.

배치 순서는 다음과 같습니다.

| 왼쪽 | 오른쪽 |
|---|---|
| 하로 | 몽돌·부싯돌 |
| 구분선 1 | 구분선 2 |

- `display: grid` 사용
- `grid-template-columns: repeat(2, minmax(0, 1fr))`
- 이미지 비율 `1:1` 유지
- 이미지 사이 간격 약 8px
- 갤러리 좌우 여백 약 24px
- 이미지의 왜곡 및 잘림 방지
- 이미지 순서 변경 금지

### 타이틀과 갤러리 간격

모바일 참조 이미지에서는 타이틀 및 구분선 아래에서 이미지 갤러리가 시작되기까지 넓은 여백이 존재합니다.

해당 간격을 데스크톱과 별도로 분석하여 모바일 미디어쿼리에서 조정합니다.

### 소개 문구 및 버튼

모바일 첨부 이미지에는 소개 문구와 버튼이 화면 하단에 나타나지 않습니다.

따라서 다음 사항을 확인합니다.

- 원래 섹션의 콘텐츠가 단순히 화면 아래에 있는 것인지 확인
- 기존 콘텐츠를 임의로 삭제하거나 숨기지 않기
- 별도의 숨김 요구사항이 없다면 갤러리 아래에 정상적으로 배치
- 모바일에서 버튼 너비, 줄바꿈 및 간격 최적화

## 7. 반응형 CSS 구현 지침

다음 사항을 준수해 주세요.

1. CSS Grid 또는 Flexbox를 활용합니다.
2. 고정 픽셀에만 의존하지 않고 `%`, `max-width`, `minmax()`, `clamp()`를 적절히 활용합니다.
3. 이미지 크기는 부모 요소의 너비에 따라 반응하도록 작성합니다.
4. 이미지 원본 비율을 유지합니다.
5. 미디어쿼리마다 필요한 CSS 속성만 재정의합니다.
6. 기존 CSS와 중복되는 선택자를 무분별하게 추가하지 않습니다.
7. 수평 스크롤이 발생하지 않도록 합니다.
8. 이미지가 화면 밖으로 넘치지 않도록 합니다.
9. 모바일에서 헤더 및 햄버거 메뉴가 정상 작동하도록 유지합니다.
10. 레이아웃 수정으로 다른 섹션이 변경되지 않도록 스타일 범위를 제한합니다.

- 불필요한 애니메이션 추가 금지
