[ 로그인 / 회원가입 기능 만들기 ]
현재 사이트는 로그인 기능이 없어.
회원가입 기능과 더불어서 로그인 기능을
구현해. 회원가입 정보는 이름,아이디,비밀번호,이메일 까지만 받아서 중복체크 등 기본 기능을 구현해. 로그인시 상단에 로그인 상태를 표시해줘(예:"사용자님 환영합니다")
로그인시에 변경될 변화는 현재의 공지사항의 글쓰기, 수정, 삭제 기능을 admin에게만 준다는 것이야. 
관리자 계정은 수동으로 등록해줘.

이름: 관리자
아이디: admin
비밀번호: 111111
이메일:admin.com@company.co.kr

- 유의사항:
로그인시 로그아웃 버튼으로 변경하여 활성화한다. 그리고 로그인버튼 클릭시
로그인 화면으로 가고 회원가입은 그 페이지 하단에 위치하게해.

- 디자인:
공지사항(Notice) 화면을 기준하여 디자인해.

- 데이터처리 : 파이어베이스로 구현.

[ 수정구현 ]
1. 로그인 페이지와 회원가입 페이지는 분리하고 로그인 페이지 하단에 링크로 회원가입 페이지로 이동 할 수 있게 수정해.

2. 회원가입시 입력되는 사용자 정보는 아래의 예와 같은 
필드로 입력되는지 확인하고 아니면 수정해.
단, 일반회원은 role 값이 'user'이고 관리자는 'admin'이다.
예)
createdAt
"2026-11-06T05:38:55.100Z"
(string)

email
"admin@admin.co.kr"
(string)

name
"관리자님"
(string)

role
"admin"
(string)

username
"admin2"


[ 추가변경요청 ]
- 현재 상단과 하단의 공통 모듈이 각 페이지에 하드코딩되어 있어. 이 부분을 하나로 만들고 모듈화하여 페이지별로 관리하지 말고 한곳에서 제어하도록 수정해.
