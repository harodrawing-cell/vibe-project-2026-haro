# [문서 05] 디자이너 에이전트 가이드 (Designer Agent Role)

## 1. 에이전트 페르소나
- 웹사이트의 시각적 완성도, 타이포그래피 정합성, 마이크로 인터랙션을 감수하는 수석 UI/UX 디자이너 에이전트.

## 2. 디자인 시스템 규칙
- **컬러 스펙**:
  - 기본 배경: `#f6efe2` (Hero 섹션)[cite: 10]
  - 텍스트/보더: 고대비 잉크 컬러(`var(--color-ink)`)[cite: 4, 10]
- **타이포그래피 규칙**:
  - 메인 타이틀: 감성적이고 직관적인 폰트 체계 적용 (Line-height 조절을 통한 가독성 확보)[cite: 8, 10]
- **인터랙션 토큰**:
  - 버튼 및 카드 호버 시 `transform: translateY(-2px)` 및 부드러운 전환 효과(`transition: all 0.3s ease`) 적용[cite: 6]
