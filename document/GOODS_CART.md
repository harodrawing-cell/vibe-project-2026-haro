# HARO GOODS 상세 및 CART

## 실행과 이동

`preview.cmd` 또는 `node scripts/preview.cjs`를 실행한 뒤 홈페이지 GOODS 카드에서 상품을 선택한다.

- 공통 상세 템플릿: `pages/goods/goods-detail.html?id=상품ID`
- 장바구니: `pages/cart/cart.html`
- JSON: `data/products.json`
- 모든 페이지의 헤더 장바구니 아이콘에서 CART로 이동한다. 배지는 저장된 총 수량이며 비어 있으면 숨긴다.

기존 메인 GOODS 8개 카드의 이미지·이름·크기와 Swiper 설정은 유지한다. 카드에 상품 ID와 링크만 연결하고 `goods-cards.js`가 JSON의 이름·대표 이미지를 기존 요소에 반영한다.

## 확인된 가격과 자료

사용자 제공 상세/장바구니 화면에서 하로 무지노트 4,500원, 배송비 3,000원, 화이트/10.5 × 14.8 cm 옵션을 확인했다. 상품명은 기존 카드의 `Haro Note (105 × 148mm)`를 그대로 사용한다. 메인 대표 이미지를 첫 번째로 사용하고, `images/used/haro-note(900x900)-001.jpg`, `-002.jpg`를 추가 썸네일·상세 이미지로 재사용한다.

제공된 외부 사이트/상품 URL은 확인을 시도했지만 현재 도구에서 열리지 않았고 검색으로도 나머지 가격을 확인하지 못했다. 사용자 답변에 따라 나머지 7개 상품의 `price`는 `null`로 두었다. ‘가격 미등록’ 표시와 장바구니 담기 비활성화로 처리한다. 가격이나 실제 판매 옵션을 임의로 만들지 않는다. 기존 카드에 적힌 기본 규격 외 추가 옵션은 만들지 않았다.

확인된 가격을 등록하려면 JSON에서 해당 상품의 `price`에 원 단위 정수를 넣고 `priceSource`도 갱신한다. 옵션은 `options: [{ id, label }]`로 관리한다. JSON에 없는 옵션은 장바구니에 담을 수 없다. 가격이 갱신되면 장바구니도 JSON을 다시 읽어 합계를 계산한다.

## 역할 분리

- `js/shop-repository.js`: 상품 JSON 로드/검증, localStorage 읽기·쓰기, 옵션 검증, 동일 상품/옵션 합산, 수량 변경·삭제 및 합계.
- `js/cart-header.js`: 공통 장바구니 아이콘·빨간 수량 배지, 같은 페이지 변경 구독, 다른 탭의 storage 이벤트 및 페이지 복귀 갱신.
- `js/goods-cards.js`: 기존 카드 내용과 JSON 연결.
- `js/goods-detail.js`: 썸네일, 옵션·수량, 총 상품금액, 장바구니 담기와 오류 안내.
- `js/cart-page.js`: 목록, 수량 변경·삭제, 빈 상태 및 주문정보 요약.
- `css/shop.css`: 공통 헤더 아이콘과 신규 페이지에 한정한 스타일.

## 장바구니 저장 규칙

키는 `haro-cart-v1`, 각 항목은 `{ productId, optionId, quantity }`다. 이름·이미지·가격을 별도 장바구니 사본으로 저장하지 않고 JSON에서 조회한다. 수량은 1~99 정수만 허용한다. 같은 상품/옵션은 합산하고 다른 옵션은 별도 항목으로 저장한다.

상품금액은 단가 × 수량의 합, 배송비는 유효한 상품이 있을 때 3,000원을 주문당 1회 합산한다. 빈 장바구니는 배송비 0원이다. 배송비는 제공 화면을 이용한 수업용 계산 규칙이며 실제 배송 정책이나 배송 일정을 의미하지 않는다.

가격·옵션이 없어진 저장 항목은 임의 삭제하지 않는다. 확인 불가 안내와 삭제 기능을 제공하고 합계에서 제외한다. 잘못된 JSON이나 저장 공간/접근 오류는 원본을 덮어쓰지 않고 메시지를 표시한다. 저장 실패 시 배지와 합계는 마지막 저장 데이터를 유지한다.

장바구니는 같은 출처의 브라우저 저장소에만 보관되며 기기 간 동기화되지 않는다. 기존 NOTICE 저장 키는 사용하거나 변경하지 않는다. 개인정보·결제 정보는 저장하지 않는다.

## 범위

상품 상세 하단의 상품 상세·구매 안내·리뷰/팬레터 영역은 로컬 안내 화면이다. 실제 결제·주문서·배송·리뷰 작성·외부 쇼핑몰 API는 구현하지 않았다. 바로 구매/주문 버튼은 비활성 상태로 명시한다. 브랜드와 공통 HEADER/FOOTER는 HARO를 사용한다.

## 검증

- 저장소: `node --test tests/shop.test.cjs`
- 브라우저: `node tests/shop-browser.cjs`
- JS 구문: 프로젝트 JS/CJS에 `node --check`

브라우저 검사는 별도 임시 Chrome 프로필에서 수행한다. 화면 자료는 OS 임시 폴더 `haro-shop-preview/`에 저장하고 사용자의 브라우저·실제 장바구니는 조작하지 않는다.
